# 🧮 Custom UI Basic Calculator
A clean, responsive, and visually engaging Basic Calculator built using HTML, CSS, and JavaScript. As seen in the project preview (CC.jpg), this calculator goes beyond a basic layout by incorporating a vibrant, anime-inspired background with a modern, semi-transparent "glassmorphism" button design.

This project performs standard arithmetic operations through an intuitive user interface while demonstrating core JavaScript concepts such as DOM manipulation, event handling, and expression evaluation.

# ✨ Features
Standard Arithmetic: Perform addition, subtraction, multiplication, and division.

Extended Operations: Includes Percentage (%) calculations and a Delete (DEL) button to easily correct single-digit mistakes.

Modern Aesthetic: Features a visually striking glassmorphism UI layered over a custom background.

Responsive & User-Friendly: Designed to look great and function smoothly across devices.

Real-Time Display: Instant visual feedback as calculations are inputted.

Clear Functionality (AC): A quick reset button to clear the entire expression.

Error Handling: Built-in safeguards to manage invalid mathematical expressions.

Organized Structure: Clean, readable, and well-documented codebase.

# 🛠️ Technologies Used
HTML5

CSS3 (utilizing modern transparency and UI effects)

JavaScript

# 📚 What I Learned
DOM Manipulation: Dynamically updating the display based on user interactions.

Event Handling: Managing click events for various operator and number buttons.

UI/UX Design: Building interactive and visually appealing user interfaces using modern CSS techniques.

Logic & State Management: Handling user input strings, calculator logic, and backspace (DEL) functionality.

Code Quality: Writing clean, maintainable, and structured frontend code.

This project was created as part of my web development learning journey to strengthen my JavaScript fundamentals and improve my frontend development skills.
